# docs/history — the evidence behind CLAUDE.md

CLAUDE.md holds the rules, contracts, invariants and traps, each with its
one-line WHY. **This directory holds the evidence behind them** — measurements,
"verified live on <date>" paragraphs, superseded rulings, incident narratives,
and the test-count log — so every session doesn't pay to read it.

One file per CLAUDE.md section. Each opens with that section's **verbatim**
text as it stood at `8c25d03` (2026-10-07), before CLEANUP-2 slimmed it.
**Never edit a snapshot; append new evidence below it under a dated heading.**
When a file and CLAUDE.md disagree, CLAUDE.md is current.

closed open-items records). This directory holds the evidence for **live** rules.
